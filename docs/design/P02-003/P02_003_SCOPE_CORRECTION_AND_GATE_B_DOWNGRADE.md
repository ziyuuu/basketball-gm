# P02-003 范围纠偏与 Gate B 阻断降级决议

- 状态：`OWNER_FROZEN`
- 生效日期：2026-08-07
- 适用范围：P02-003、Draft PR #15、P02-003 Gate B 审核
- 后续产品所有者：P02-006（名单、位置适配与产品助教轮换）

## 1. 纠偏原因

P02-003 的原始目标是证明无干预 Headless Model B 能够独立、确定、可解释地完成比赛。
P02-003 只需要 `internal/test` 中性轮换和强制合法补位维持比赛运行；玩家轮换、位置适配、
浅/平衡/深助教预设及完整产品轮换由 P02-006 负责。

2026-08-06 定点修订实施后，审核把下列实现精度逐步提升为 Gate B 阻断：

- 44 项行为逐项精确能耗审计；
- non-selectable 行为的精确 actor/target 选择；
- 一次替换同时保存触发原因和错位原因；
- 主位置恢复、防振荡和主动轮换阈值的完整状态机。

这些要求提前建设了 P02-006，并且部分语义没有唯一冻结答案，导致 r4～r6 在实现与审核间
反复补规则。本决议撤销这类审核扩张，把 P02-003 恢复到原始切片目的。

## 2. 权威优先级

本文件只覆盖以下材料中与 **P02-003 Gate B 验收粒度和阻断等级** 冲突的条款：

- `P02_SINGLE_MATCH_ENERGY_AND_FORCED_MISMATCH_AMENDMENT.md` 第 2.2、5.2、7、8 节；
- `docs/P02_DEVELOPMENT_PLAN.md` 第 7.4 节；
- Draft PR #15 r4～r6 审核中新增的精确参与者、双原因和恢复状态机要求。

本文件不撤销产品层的单场体力、能力档位、主位置优先和无人可补时允许强制错位的方向。
这些产品语义在 P02-006 接入正式名单和助教轮换时继续有效。P02-003 已实现的内部细节可以
保留，但不得因此被解释为 P02-006 的最终产品规则。

## 3. P02-003 的最低 Gate B 合同

P02-003 的体力与补位只按以下可观察结果验收：

1. 每场全员从 `100` 单场体力开始，赛前训练状态不改变开场体力。
2. 在场时间产生基础消耗；真实比赛行为总体上产生追加消耗；耐力高的球员在相同负荷下
   消耗更少；体力档位按冻结边界影响非耐力比赛能力。
3. 替补席、节间、中场、加时和暂停的恢复来源保持冻结方向，不要求在 P02-003 完成最终
   平衡值。
4. 犯满球员离场且不得返场；有合法同位置替补时优先补位；没有时允许确定性强制错位并
   只结算一次统一惩罚。
5. `internal/test` 中性轮换不得产生非法阵容、非终止振荡或 watchdog 超限；同输入下选择和
   结果必须确定。
6. OFFICIAL、FRIENDLY、SCRIMMAGE 均能结束；统计恒等式成立；
   `step == runToEnd == replay` 的 Event/Fact/Anchor/result/identity 保持一致。
7. `pnpm check`、P02 evidence manifest、B8 性能与既定方向场景通过。

## 4. 明确降级为非阻断或延期

下列项目不再阻塞 P02-003、B8 或 Gate B：

- 10 项 non-selectable 行为是否各自选择了篮球语义上唯一的 target；
- ORB、DRB、BOXOUT 的追加消耗具体记到投手、对位者还是争抢失败者；
- 44 项行为是否都有独立、逐项可审计的体力调用路径；
- 单个 `SUBSTITUTION` Event 是否同时保存“为什么触发替换”和“为什么发生错位”两层原因；
- 主位置球员在 `internal/test` 中性轮换中恢复的精确边界、保护期和主动换出优先级；
- 只证明内部 helper、registry 或测试写法的覆盖完整度，而没有对应玩家可观察失败的事项。

其中，行为参与者精细化属于以后确有表现或平衡需要时的普通改进；正式轮换、位置恢复、
防振荡和解释字段由 P02-006 统一设计与验收，不从 P02-003 的测试政策反推产品规则。

Candidate `3489a70376ba1e02b12e8cf2a223499111fe7929` 的以下事项按本决议降级：

Candidate；后继只需同步本决议、修复格式和 evidence manifest，并重新取得成功 CI。

## 6. 后续审核边界

后续 P02-003 审核只能把第 3 节的可观察失败列为阻断。若要把第 4 节任一项目重新提升为
Gate，必须先由 Owner 修改本决议，不能在代码复审中临时追加语义。

B8 在本纠偏后恢复：它只负责既定参数校准、方向场景与性能证据，不得借校准重新引入
逐行为能耗审计或产品级轮换系统。P02-004 仍等待完整 Gate B。
