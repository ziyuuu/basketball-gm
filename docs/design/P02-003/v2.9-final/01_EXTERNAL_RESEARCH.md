## B. Mature Model Comparison（成熟模型对比）

### B1. Basketball GM / ZenGM

**机制**：每节每回合驱动。一次 `simPossession` = 一个进攻回合：后场推进 → 可能失误 → 前场推进 → 一次出手判定（封盖/命中/不中+犯规/不中）。进攻篮板直接重进 `simPossession`，视为全新回合。**无进攻时钟违例**（24s 只是出手时间上界）。**无几何**。**无注入 RNG**（不可复现）。疲劳按秒衰减。轮换由价值×疲劳×犯规×位置有效性涌现。

**借用的模式**：
- 单点 `pickPlayer` 加权随机原语（本项目用于行为主体选择，但改为带 `drawKind` 的 keyed RNG）
- 判定树的清晰结构（block → make → miss+foul → miss → rebound）
- 全部平衡旋钮外置为数据（本项目用参数 Registry）
- 轮换用价值×疲劳×犯规+位置有效性（本项目用内部测试轮换）

**不借用的部分**：
- 无进攻时钟 → 本项目冻结 30s 违例（F-06, F-23）
- `Math.random()` → 本项目 keyed deterministic RNG
- 无几何 → 本项目有场景/对位修正但不做完整几何
- 线性 `probMake` 拦截公式（0 属性仍 54% 命中率）→ 本项目用有上下界、属性驱动的标定公式
- 单一 `pf` 无犯规分类 → 本项目区分犯规类型（防守/进攻/技术）
- forceWin 重试循环 → 本项目不用

### B2. NBA 2K

**机制**：5 类 22 属性 + 徽章（隐藏乘数，属性阈值解锁 5 档）+ Build + 倾向（0-99，"多常做"）。徽章自动触发，作用于特定动作。

**借用的模式**：
- "属性决定上限、倾向决定频率"的二分（与 F-55 完全一致）
- 徽章作为行为选择/成功概率的基础加成（与 F-66 完全一致）
- Build 差异 = 同属性不同行为分布
- 位置行为池（PG/SG/SF/PF/C 默认池）

**不借用的部分**：
- 动画/物理/输入层（投篮时机、运球组合、接触扣篮动画）→ Headless 不需要
- 徽章属性阈值解锁 → P02-003 只设计徽章接口，不设计获取（F-68）
- OVR 参与 → 冻结 OVR 不参与比赛（F-63）
- 徽章数量 77+ → 本项目徽章接口尽量小

### B3. Possession / Markov / Event-driven 模型

- **Markov**：持球者×区域×防守 → 吸收态。本项目不照搬完整 Markov（会退化为无球跑位），但借用"吸收态/回合终止"思路：每次行为是状态机里的一次转移，命中/失误/篮板/犯规/违例是吸收事件。
- **进攻时间切片**（M15）：接近 24s 出手压力上升 → 本项目"接近 30s 增加出手压力"（F-22）。
- **Oliver 四要素**（M16）：作为平衡校准维度：eFG%、TOV%、ORB%、FTr 是判断真实性的四根柱子。设计目标让星级差异由四要素自然产生。
- **离散事件仿真**（M17）：本项目时间模型 = 事件驱动，行为消耗 1-5 模拟秒，时钟按行为推进。
- **确定性 RNG**（M18-20）：keyed/hash RNG + 整数定点（本项目 `drawKind/localIndex` 即 keyed 思路）。

### B4. 额外成熟实现（OOTP / WhatIfSports 模式）

- OOTP：play-level 事件引擎，玩家级判定 + 联盟总量校准；play-by-play 文本是事件的美化层。→ 本项目"Headless 决定事实，文字直播只消费事件"（F-13, F-14）一致。
- WhatIfSports：box score 因果一致（出手产生篮板，球权有限）。→ 本项目"统计由事件累积"（F-95）一致。
- Football Manager：每 0.25s 每个球员决策。→ 太重，本项目不采用。

## C. Realism Baseline（真实性基准）

### C1. 规则基准

本项目冻结规则（4×10 模拟分钟、30s 进攻时钟、5 犯规离场、平局加时 5 分钟）与 **NCAA 女篮规则完全一致**（R1, R4-R6）。因此：
- **[设计]** 以 NCAA 女篮规则为唯一规则口径，简化 NFHS 差异（4×8min/35s 时钟）不入模型，仅在文档注明。
- **[设计]** 三分线：设计上按 NCAA 22'1.75" 概念处理（三分行为与两分行为的判定区分），不实现像素级距离。
- **[设计]** 加时按 NCAA：5 分钟；**P02 无跳球，加时首段球权用确定性 keyed draw（`03` §4.1）**。
- **[设计]** 队内赛允许平局（冻结 F-07），不出加时。

**N06 有意偏离声明**：P02 加时首段球权用确定性 keyed draw，**不同于 FIBA/NCA 的跳球或 AP 交替拥有规则**——这是 Owner 确认的项目简化，特此标注为有意偏离，不声称完全对齐现实规则（v2.3 复审 Non-Blocking 6）。第 2~4 节仍采用 AP 交替拥有（`03` §4.5），与 FIBA 12.6 一致；仅加时首段与开场首段采用 keyed draw 简化。

## D. 研究结论对本设计的硬约束

> **v1.1 修订**：以下设计结论中，凡是 P02-002 真实合同/基线已冻结的内容以仓库为准（`00` Authority Conflict Log）。本清单保留研究层面的外部事实价值，设计落地见 `05`（基线 §12.4 公式）。
