and restored RNG snapshot.

## Re-signed attack matrix

The tests generate valid saves, apply one named mutation, repair unrelated sequence and (where
applicable) all following balances plus the final budget, then recompute both `snapshotHash` and
the outer save checksum.

Seventeen variants cover:

- deleted and duplicated settled annual grants;
- wrong school year;
- annual grants moved to weeks 41, 81, and 121;
- one changed annual amount;
- all annual amounts and `budget.annualGrant` changed together;
- either completed-school-year counter changed;
- one internal `balanceAfter` changed while the terminal balance is preserved;
- terminal budget changed while the ledger is preserved;
- initial-grant amount only, balance only, duplication, and missing identity;
- an annual grant inserted for an unsettled future year.

Every variant asserts:

1. the recomputed snapshot hash matches the mutated snapshot;
2. the recomputed save checksum matches the mutated envelope;
3. `GameStateSchema` rejects it;
4. the expected target issue message and path are present;
5. `SaveEnvelopeSchema` rejects it;
6. `restoreSession` rejects it.
